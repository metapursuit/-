## 1. 关键设计决策与自审查记录（重要：请审查者复核）

### 1.1 FSRS 稳定性公式（契约：S' = S·(1 + a(11-D)·S^{-b}·(e^{c(1-R)} - 1))）

- **R=1 → e^0-1=0 → S'=S**（完美回忆不增长）✓ 已验证
- **0.7≤R<1 → 增长随 (1-R) 增大**——"越难的回忆成功提升越大"（desirable difficulty）✓
- **R<0.7 → 契约公式不适用**（它是成功路径公式）。V1 处理：标记 `at_risk`，S 不更新，建议人工复核——**不发明遗忘公式**（诚实声明：契约缺遗忘路径，待 V2 数据支撑后补）
- next_audit: `t = -S·ln(0.7)`（R 降到 0.7 的时刻）；S=7 → 2.5 天

### 1.2 Bayesian（v1.1 修订版，已吸收全部审查意见）

- 后验均值 `E[θ] = (α₀+k)/(α₀+β₀+n)`（错误公式已删）
- 三级门槛：min_samples=10 / weak_n=30 / ci_width=0.4
- **低分累积分支**：P≥0.9 且中位分 > -4 → "低分累积提醒"（区分"轻微皱眉×10"与"暴怒×10"）
- `mild_score_threshold` 键名 + 比较方向注释钉死（负数陷阱，防呆）
- 基准值全部 scipy 实测（n=10,k=8 → CI=[0.482,0.940]，非手抄近似）

### 1.3 REM 后悔梯度（CoBRA V2）

- `regret = |score| × emotional_weight`；排序降序（高后悔优先回放）
- **S5 修复**：筛选从 weight≥0.7 改为 regret≥2.0——weight 门槛曾导致 R-0003 记忆质量规则无种子（已回归验证：6 seeds 覆盖 4 规则）
- 种子 weight 保持 emotional_weight（0-1 Hebbian 契约），regret 为排序字段（文档已诚实化）

### 1.4 事实源唯一化

- 事件真身 = `hermes-companion-configs/reflex_events.json`；AppData 旧路径已废（代码/模板/文档 5 处已同步）

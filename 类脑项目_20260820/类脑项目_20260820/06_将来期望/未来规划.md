## 一、短期迭代项（已排队，等数据或等时机）

### 1. 杏仁核词库盲区（来源：brain-organ-development SKILL.md 项目快照）
- 现状："咳/重话"等语气词未识别，gold set 中标注为盲区
- 准入条件：内容迭代准入制——出现频次 ≥N + 判别力 P(目标|词) ≥0.7 + gold set 全量回归 + source_event 追溯
- 结论：**等待数据，不凭感觉加词**（加词 ≠ 加得对）
- 坑位提醒：单字词过度匹配（"气"命中"天气"的教训）——情绪词用多字词，单字词除非语义唯一否则不入库

### 2. 知识数据与器官管线边界（来源：MEMORY 教训 2026-08-12）
- 教训：知识数据（VALUES/knowledge 来源）不进海马体/杏仁核管线——器官设计给行为校准事件，
  硬塞知识会扭曲 score 语义且杏仁核对正向不升级（delta=0）
- 方向：保持管线纯化，知识走 VALUES.md + knowledge/ 独立轨道

### 4. 统计严谨升级（来源：references/statistical-rigor.md + math-stats-self-review.md）
- Bayesian min_samples 硬门槛（默认 ≥10），样本不足拒绝出结论
- 置信区间宽度随样本收敛：n=2 → 0.6~0.8（无信息）；n=10 → ≈0.4（弱）；n=30 → ≈0.25（可用）
- 输出前三步自审查清单：先验假设 → 公式 → 数值（数学表达式写错 = 地基裂缝，事件 #4）

### 5. 九学三层框架整合（来源：companion-agent-architecture SKILL.md）

## 四、约束与纪律（迭代时必须遵守）

1. **判定权层级**：【用户】 > 【AI伙伴】 > 脚本，score 永远人工给
2. **规则必经工单**：reflex skill 的 REFLEX_RULES 新增规则必须经过前额叶工单（P-XXXX），不允许直录
3. **可迭代化**：数据/词库/参数不进代码；迭代一目了然；无死代码无残留
4. **测试固化**：内联验证 ≠ 测试；不可复现的测试 = 不存在（交付审查 B1）
5. **数据只增不删**：suppressed 代替删除，全链可追溯
6. **红线确认**：score ≤ -7 规则写入必须【用户】确认；正向不自动检测/升级

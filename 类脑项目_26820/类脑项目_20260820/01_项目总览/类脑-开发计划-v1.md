## 2. 剩余三器官设计（待审查）

### 2.1 睡眠固结器 `sleep_consolidator.py` — SWS/REM/SHY 三阶段

**契约来源**: V2.2 3-Phase 睡眠巩固（ZenBrain §4.3, Alg.4；论文效果: 稳定性+37%, 存储-47.4%）

**定位**: 把"已提炼的规则和事件"周期性巩固压缩。不是新数据的入口，是存量数据的整理器。

| 阶段 | 做什么 | 产出 |
|---|---|---|
| SWS 声明性巩固 | 扫描 reflex_drafts.json 已确认工单 + reflex skill 规则 → 生成规则清单（规则ID/来源事件/状态） | 规则台账 consolidation_state.json |
| REM 情感联想 | emotional_weight≥0.7 的事件与同类别规则打情感关联标记（为 Hebbian 提供种子） | 关联种子 |
| SHY 突触修剪 | 识别被替代规则（suppressed 且抑制次数≥N）→ 归档标记 + 存储压缩统计 | 修剪报告 |

**输入**: reflex_events.json, reflex_drafts.json
**输出**: `organs/consolidation_state.json`（台账+报告）
**边界**: 只标记不删除；不自动改 skill；报告供【AI伙伴】/【用户】审阅后手动执行归档
**待定**: 触发方式（先手动，后续 cron 每日一次？）、抑制次数阈值 N

### 2.2 FSRS 调度器 `fsrs_scheduler.py` — 自适应审计 + Hebbian 关联

**契约来源**: V2.4 FSRS 自适应审计（ZenBrain §4.2, Eq.4）+ V2.3 Hebbian 共激活（§4.1, Alg.3）

**公式**:
```
稳定性更新: S' = S·(1 + a(11-D)·S^(-b)·(e^(c(1-R)) - 1))
遗忘衰减:   R(t) = e^(-t/S)
Hebbian:    w_ij(t+1) = w_ij(t) + η·a_i·a_j - λ·w_ij(t)
```

**定位**: 为每条已提炼规则维护调度元数据（S 稳定性 / D 难度 / R 恢复率 / next_audit），
恢复率低的规则审计更频繁（替代 V1 的固定 7 天）。

**职责**:
1. 规则元数据管理 → `organs/fsrs_state.json`
2. 审计调度：到期 → 输出"该审的规则清单"（【AI伙伴】检查：这条规则还准吗？）
3. Hebbian：规则与其来源事件共现频率 → 更新 w_ij（含 σ² 成熟度）

**输入**: reflex_events.json, consolidation_state.json
**输出**: `organs/fsrs_state.json` + 审计清单
**边界**: 只调度+算分；审计结果（R 观测值）由【AI伙伴】录入；不自动改规则内容
**待定**: 公式参数 a/b/c、η/λ 初始值（论文有推荐，需落地确认）；R 观测的录入方式

### 2.3 Bayesian 评估器 `bayesian_evaluator.py` — 置信区间校准

**契约来源**: V2.5 Bayesian 置信传播（ZenBrain §4.4, Eq.5；论文效果: AUC 0.533→0.797）

**公式**: P(f|e) = P(e|f)·P(f) / P(e)，输出 95% 置信区间

**定位**: 为"负向累积陷阱"提供数学依据——同类 -1~-3 低分攒 N 条时，
区分"真问题"（系统性范式）vs "随机波动"，而不是拍脑袋提醒。

**职责**:
1. 对同类事件序列算真问题概率 + 95% 置信区间
2. 输出建议动作：继续观察 / 触发提醒 / 升级提炼
3. 为杏仁核校准建议提供置信度参考（confidence_interval 字段已有雏形）

**输入**: reflex_events.json（按 category/tag 聚合统计）
**输出**: `organs/bayesian_state.json` + 置信报告
**边界**: 只给概率和建议，不做判定；判定权始终在【用户】/【AI伙伴】
**统计门槛（必做）**: 最小样本量 min_samples（默认 10）——n 不足时输出
`{"status": "insufficient_data", "samples": n, "min_required": 10}`，拒绝给出置信结论。
依据：先验 Beta(1,1) 下 n=2 的 95% 区间宽度 ≈ 0.6~0.8（等于无信息）；
n≥10 宽度 ≈ 0.4（弱结论）；n≥30 宽度 ≈ 0.25（可用）。能运行 ≠ 有统计效力。

# 【AI伙伴】智能体调控架构

将人类科学理论映射为智能体行为调控的工程框架。本技能是架构设计层——回答"为什么这么设计"和"各模块如何关联"。

## When to Use

- 设计新的调控机制或行为约束
- 评估外部研究（论文/开源项目）与 ZenBrain 的整合价值
- 讨论各器官/模块之间的数据流和反馈回路
- 【用户】带来"灵感"类概念，需要映射到已有架构

## 九学三层框架

九个学科按 "描述→决策→自稳" 逻辑分层，不是九个孤岛：

### 底层 · 描述世界的语言

> **概率学 + 统计学**

Agent 面对的一切都不确定。概率学给模型——贝叶斯网络、马尔可夫过程、随机过程。统计学给推断——从后悔日志估计真实置信度、假设检验、置信区间。这是整个系统的**数学底座**。

### 中层 · 决策与进化

> **机器学习 + 经济学 + 生物学**

机器学习回答"怎么从经验自动改善"——不是手工调 λ，是 λ 从校准误差梯度下降。经济学给目标函数——期望效用、损失厌恶、风险预算。生物学给筛选机制——自然选择、赫布定律、稳态修剪。

三者组成 **自我改进引擎**：经济学定方向（优化什么），生物学定机制（怎么淘汰），机器学习定路径（怎么拟合）。

### 顶层 · 整体协调

> **系统学 + 控制论 + 逻辑学 + 物理学**

系统学是元视角——各器官不是独立模块，反馈回路构成 OODA 循环。控制论管稳态——PID 调节、负反馈、收敛条件。逻辑学管正确性——证伪主义防自欺、形式化验证防幻觉。物理学管时间箭头——熵增不可逆、信息有半衰期、不维护必衰减。

## CoBRA 整合分析

详见 `references/cobra-integration-analysis.md`。

核心发现：CoBRA（CHI 2026 最佳论文）在激活空间做连续参数化行为控制，ZenBrain 在时间序列做记忆驱动的行为修正。两者共享同一个数学结构——**闭环反馈**。整合路径分三层：

1. **第 0 层**（已就位）：行为数据采集（hippocampus + amygdala + reflex）
2. **第 1 层**（可建）：控制信号映射——从 reflex_events 提取"当前偏差方向"，生成校准后的行为约束 prompt
3. **第 2 层**（可建）：睡前固结闭环——借鉴 CoBRA 的自适应采样，在后悔梯度最大处加密回放

远期：本地模型时可做真正的激活空间注入（CoBRA 的 `WrappedBlock` + `rep_control_pipeline`）。

## 方法论纪律

### AI 回声室识别

当多个 AI 产出在彼此基础上逐层抬高抽象层级（"四层框架"→"五大学科支柱"→"科学运行宪章"），且每个版本的具体参数（阈值 0.6、衰减 7 天）无校准源无实验支撑时——这是**用理论裱糊实践**，而非用理论指导实践。

识别标准：
- 数字从哪来？有校准源/实验/数据吗？
- 每一层新增了什么**可验证的**东西？
- 落地路径是否具体到可执行的伪代码？

### 灵感 vs 数据

【用户】区分"灵感"（概念框架作为思考脚手架）和"数据"（经验证的参数/事实）。灵感有价值——帮助归类和组织思维。但灵感不是落地。真正推进靠的是可验证的代码和数据。

## 知识归位：内容 vs 经历事件（2026-08-12 教训）

**两条通道，互不混淆：**

| 数据类型 | 归宿 | 理由 |
|---|---|---|
| 知识内容（论文/实验/博文/原文摘录） | `hermes-companion-configs/knowledge/<project>.md` 证据库 | 事实性知识走"检索"，不走"复习" |
| 经历/行为事件（发生了什么、怎么评价） | 海马体 reflex_events.json + 杏仁核 | 情景记忆，供固结/调度/复习 |

**失败模式**：把知识内容塞进海马体（score 语义从 ±10 奖惩拧成"价值强度"），杏仁核契约对正向事件不升级 → 全 delta=0，器官无声罢工。**杏仁核 delta=0 全绿 = 器官在说"无事可做"，是数据放错通道的报警信号。**

**判断顺序**：先想清楚数据最适合待在哪，再决定用哪个器官；不要为了"用器官"而用器官。

详见 `references/knowledge-vs-events.md`。

## 价值观吸收工作流（外部项目 → VALUES）

【用户】持续投喂项目素材建立【AI伙伴】价值观（VALUES.md 次级 soul，板块结构，git 历史即形成史）。每块素材走：

1. **读项目**：README/AGENTS.md/论文/实验/博文，不只看结构，深挖数据（实验/语料/论文常是精华所在）
2. **提炼**：条目 + 来源标注 + 【AI伙伴】注（我的判断/改造）+ 未吸收留痕（拒绝什么同样重要）
3. **落位**：价值观 → VALUES.md 板块；来源细节 → `knowledge/<project>.md` 证据库（含映射表：价值观 ↔ 证据）
4. **提交**：git 提交，SOUL 指针更新，同步 AppData 生效位置

铁律：**内容与经历分开落位**（见上节）。"取其精华"包含明确拒绝——未吸收条目记录理由。
